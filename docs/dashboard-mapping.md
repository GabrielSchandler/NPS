# Mapeamento pendente

Para acelerar a copia do dashboard atual para a web, preciso destas referencias:

## Telas

- print de cada aba do Excel
- filtros visiveis
- cards, tabelas e graficos que realmente importam

## Fontes

- `pesquisa_hora_a_hora_chamada`: modulo CRM `389`
- `ura_satisfacao_analitica`: modulo CRM `446`
- `sms_usuario`: modulo CRM `516`
- formato do arquivo exportado: CSV, XLSX ou outro
- exemplos reais ou anonimizados

## Regras de negocio

- como o NPS e calculado hoje
- quais recortes precisam existir: periodo, unidade, vendedor, operador, carteira, produto
- quais colunas sao obrigatorias para identificar um registro unico

## Rotina operacional

- com que frequencia o relatorio e baixado hoje
- se existe mais de uma empresa, unidade ou ambiente
- se o login no CRM usa MFA, captcha ou outra protecao
